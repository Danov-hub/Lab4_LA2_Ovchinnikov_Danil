# Задание 1 (List)

## Задача 11 

### Текст задачи
Составить программу, которая формирует список L, включив в него по одному разу элементы, которые входят одновременно в оба списка L1 и L2.

### Алгоритм решения
1. Вводятся два списка целых чисел `L1` и `L2` с клавиатуры с проверкой корректности ввода (`int.TryParse`).
2. Создается пустой результирующий список `L`.
3. В цикле проходим по элементам списка `L1`.
4. Для каждого элемента проверяем: содержится ли он в списке `L2` (метод `Contains`) и еще не добавлен ли он в результирующий список `L` (чтобы избежать дубликатов).
5. Если оба условия выполнены, элемент добавляется в `L`. Выводится результат.

# Задание 2 (LinkedList)

## Задача 11

### Текст задачи
В конец непустого списка L добавить все его элементы, располагая их в обратном порядке (например, по списку из элементов 1, 2, 3 требуется построить список из элементов 1, 2, 3, 3, 2, 1).

### Алгоритм решения
1. Вводится непустой список `LinkedList<int>` с проверкой ввода.
2. С помощью свойства `Last` находим последний узел списка.
3. Запускаем цикл, который идет от последнего узла к первому (через `Previous`).
4. На каждой итерации значение текущего узла добавляется в конец списка с помощью метода `AddLast`.
5. В результате в конец добавляются элементы в обратном порядке. Выводится измененный список.

# Задание 3 (HashSet)

## Задача 11

### Текст задачи
Есть перечень торгово-развлекательных центров (ТРЦ) города. Студенты группы любят посещать ТРЦ. Известно для каждого студента, в каких ТРЦ он побывал. Определить:

• в какие ТРЦ из перечня ходили все студенты группы;

• в какие ТРЦ из перечня ходили некоторые студенты группы;

• в какие ТРЦ из перечня не ходил ни один из студентов группы?

### Алгоритм решения
1. Вводится общий перечень ТРЦ города в виде множества `HashSet<string>`.
2. В цикле вводится информация о посещениях каждого студента. Для хранения данных всех студентов используется массив множеств (`HashSet<string>[]`), что позволяет строго соблюсти условие использования только коллекции HashSet (без применения List). Каждое посещение отдельного студента также сохраняется в `HashSet`.
3. Для поиска ТРЦ, где были все, создается копия общего перечня и последовательно применяется `IntersectWith` с множествами каждого студента (пересечение).
4. Для поиска ТРЦ, где были некоторые, создается пустое множество и применяется `UnionWith` со множествами студентов (объединение).
5. Для поиска ТРЦ, где не был никто, берется общий перечень и применяется `ExceptWith` (вычитание объединения из общего перечня).

# Задание 5 (Dictionary)

## Задача 11 

### Текст задачи
В соревнованиях по многоборью участвуют N спортсменов. Программа должна выводить результирующую таблицу, содержащую список спортсменов, отсортированный по убыванию суммы баллов, набранные суммы и занятые места. Исходные данные хранятся в текстовом файле.

### Алгоритм решения
1. Вызывается вспомогательный метод `FillSportsmenFile`, который создает файл `sportsmen.txt` с тестовыми данными (если файла нет).
2. Файл считывается в массив строк. Из первых двух строк считываются N и M.
3. Для подсчета суммы баллов используется `Dictionary<string, int>` (ключ - ФИО, значение - сумма).
4. Данные из словаря переносятся в массивы `names` и `totalSums`.
5. Массивы сортируются по убыванию суммы баллов.
6. Вывод мест реализован с плотной нумерацией: если суммы баллов равны, спортсмены делят место, а следующий получает место на 1 больше (например: 1, 1, 2).

# Задание 7 (Перегрузка операций)

## Задача 11

### Текст задачи
Унарные операции:
! вычислить длину диапазона, результатом должно быть вещественное число; 
++ расширить отрезок на 1 вправо и влево

Операции приведения типа:
int (неявная) – результатом является целая часть координаты х;
double(явная) – результатом является координата y.

Бинарные операции:
- LineSegment целое число (левосторонняя операция, уменьшается координата х);
- целое число LineSegment (правосторонняя операция, уменьшается координата y);
  
< LineSegment d – результат равен true, если отрезки пересекаются, и false – в противном случае.

### Алгоритм решения
1. Перегружен унарный оператор `!`: вычисляется `Math.Abs(y - x)`.
2. Перегружен унарный оператор `++`: возвращает новый объект со смещением `x - 1` и `y + 1`.
3. Перегружены операторы приведения типов: `implicit operator int` (возвращает `(int)x`) и `explicit operator double` (возвращает `y`).
4. Перегружена левосторонняя операция `-`: уменьшает `x` на заданное число.
5. Перегружена правосторонняя операция `-`: уменьшает `y` на заданное число.
6. Перегружены операторы `<` и `>` (обязательно парой): внутри вызывается логика метода `IsIntersect`.
